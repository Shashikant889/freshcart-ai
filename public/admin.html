📖 LSTM Recurrent Cell Equations (Academic Viva Reference)

Deep Learning Rigor

The Long Short-Term Memory (LSTM) cell overcomes vanishing gradients in multi-horizon sales forecasting via three gating mechanisms:

Forget Gate ($f_t$):
$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$
Controls how much of prior sales context to discard.
Input Gate ($i_t$):
$i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)$
Regulates intake of new price/promotion features.
Cell State Update ($c_t$):
$c_t = f_t \odot c_{t-1} + i_t \odot \tanh(W_c [h_{t-1}, x_t] + b_c)$
Uninterrupted gradient highway across 14 lookback days.
Output Gate ($o_t$):
$o_t = \sigma(W_o [h_{t-1}, x_t] + b_o); \quad h_t = o_t \odot \tanh(c_t)$
Emits recurrent state to dense linear projection layer.
